# 桌面工具交互约定

## 默认窗口

搜索框在最上方，与记录状态/暂停按钮和「更多操作」同一行；下一行仅放日期、应用筛选与记录数。余下空间优先用于 56px 高的虚拟化结果行，显示应用标识、窗口标题、应用名和时间。保留现有进程首字母作为图标降级标识，不伪造原生应用图标或额外启动图标采集服务。时长、完整标题、删除和排除操作在详情中。

没有侧边导航、宣传口号、欢迎头图或装饰卡片。首次未同意时，在同一历史区域上方显示一段必要隐私说明及开始按钮；未经同意不采集。启用后确认区消失，始终回到历史并聚焦搜索。

## 键盘

- 进入/重新进入插件：关闭临时面板和详情，回到历史，搜索自动聚焦。
- 输入：120ms 合并输入后查询，不等待 Enter；查询未完成时 Enter 不打开旧结果。
- ↑↓：选择并自动滚动可见结果；当前页末尾继续向下时加载下一页并选中新结果。
- Enter：打开所选详情；关闭详情后恢复原焦点。
- Esc：优先关闭详情/确认/更多菜单；次级页面返回历史；有关键词时清空；空查询时调用宿主 hideMainWindow，隐藏界面而非结束采集。
- Ctrl/Cmd+K：返回历史并聚焦搜索；更多菜单可用 Tab、Enter、↑↓、Home/End 操作。
- 输入法组词期间不截获 Enter/Esc/方向键。

记录暂停状态不因换页面或隐藏窗口而改变，采集与 SQLite 模块本轮未修改。

## 次级入口与滚动

「更多操作」包含设置、统计、导出 JSON/CSV。设置分为记录偏好、排除应用、本地数据三个短面板，排除使用逗号分隔进程名。统计每页三项，长标题每段 60 字符逐段查看，复制仍复制完整标题。导出保持当前日期范围语义。

窗口和次级面板不创建网页式滚动区，只有历史长列表纵向滚动；表单单行输入的文本光标移动仍使用原生行为。必要错误、确认和反馈保留，不为节省空间隐去实际错误。

## 验证范围

浏览器自动化覆盖键盘跨页、菜单、Esc 层级、宿主重进回调、设置/导出、统计分页、长标题无溢出、DPR/窗口矩阵、10 万条测试数据虚拟列表。小窗口次级面板及长标题以 480×360 检查，不使用测试数据充当真实历史。

真实宿主自动聚焦/快捷键拦截、Windows 100%/125%/150% 的字体栅格化、后台保活和“一秒内理解”的实际用户体验仍须人工核对，不能用 headless 测试替代。本轮不声明启动延迟已达到一秒 SLA。
