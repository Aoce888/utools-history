# Windows 开发预览交付说明

本包用于 uTools 开发者工具加载测试，尚非正式发布，没有版本标签或商店安装包。

完成本地活动记录、SQLite 保存、时间线/搜索/日期应用筛选、详情/键盘导航、统计、引导、暂停、排除、删除确认、保留期、导出和深浅主题。保留 M1 Win32 实验代码，当前产品使用解耦的连续采集适配器。

加载：解压包后导入其中 `plugin.json`，无需运行开发服务器；首次明确同意后采集。包内不含用户数据库、测试数据、账号/AI/云端服务。校验值在 ZIP 同目录 `.sha256` 文件。

已完成自动化范围及真实测量见 [测试结果](test-results.md)，宿主验收统一见 [待人工验证](manual-verification.md)。每秒轮询可能遗漏短暂切换；仅在插件进程存活时记录；不安装自启动；崩溃最多可能丢失最近约 5 秒快照；数据库未加密。窗口标题无法保证恢复 URL/文件路径，不提供虚假打开能力。
